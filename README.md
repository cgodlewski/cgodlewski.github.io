# Christophe J. Godlewski — Academic Website

Static personal academic website published with GitHub Pages.

## Updating the content

- Update the publication source in `data/publications.ts`, then run `node generate-publications.mjs`.
- Update the conference list in `generate-conferences.mjs`, then run `node generate-conferences.mjs`.
- The generated pages are `publications/index.html` and `conferences/index.html`.
